# PakStyle Features

## Theme Features
- Custom Shopify theme built with Online Store 2.0.
- Responsive homepage, collection pages, product pages, cart drawer, and footer.
- Dynamic sections and theme settings.
- Mobile-first design and optimized layout.
- SEO-friendly Liquid templates and metadata.

## Headless Store Features
- Next.js 14 App Router storefront.
- Shopify Storefront API integration for products, collections, and search.
- Homepage hero section and featured products.
- Product listing with sort/filter capabilities.
- Product detail views with image gallery and variant selection.
- Collection pages with product grids.
- Cart page with quantity controls and checkout link.
- Search experience with query-driven results.
- Tailwind CSS styling and brand identity.

## App Features
- Express.js custom Shopify app.
- Dashboard KPI route connected to Shopify Admin GraphQL.
- Bulk product tag editor route.
- Low stock alert route.
- Discount code generator route.
- App UI views for dashboard, products, and discounts.

## API Integrations
- Shopify Storefront API for headless storefront data.
- Shopify Admin API for app dashboard and inventory tasks.
- GraphQL queries and mutations for cart, products, and collections.

## Performance Optimizations
- Server-side rendering on Next.js pages.
- Minimal client-side hydration for interactive components.
- Tailwind CSS for optimized styling.

## SEO and Accessibility
- Clean semantic markup across pages.
- Dedicated metadata support in Next.js layout.
- Accessible navigation and responsive design.

## Mobile Optimizations
- Mobile-friendly header and layout.
- Adaptive product grid and image presentation.
- Touch-friendly buttons and input controls.
