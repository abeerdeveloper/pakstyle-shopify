# Screenshot Guide

This file is a placeholder to document how to capture and add screenshots for the PakStyle project.

## How to Take Screenshots
- Use a reliable tool such as Lightshot, ShareX, or your operating system's screenshot utility.
- Capture the homepage, product pages, cart, collection pages, and admin app screens.
- Focus on full-width views and mobile/responsive states.

## Where to Add Screenshots
- Add screenshot files into a repository folder such as `/docs/screenshots`.
- Reference those images in `README.md` under the Screenshots section.
- Update README placeholders with markdown image links.

## Recommended Tools
- Lightshot: https://app.prntscr.com/
- ShareX: https://getsharex.com/
- Native tools: Windows Snipping Tool, macOS Screenshot, or Linux Flameshot.

## Notes
- Keep filenames descriptive, such as `homepage.png`, `product-page.png`, `cart-page.png`, `admin-dashboard.png`.
- Use high-resolution captures for documentation.
